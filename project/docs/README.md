# NexFund Archive Notes

This folder represents the working, unified project scaffold generated by merging the two Bolt archives found in the repository.

## Included evidence

- `.bolt/config.json` reference: `bolt-vite-react-ts`
- Vite + React + TypeScript application shell
- Tailwind + PostCSS tooling
- Supabase integration points for backend functions and session management
- Documentation files from the original Bolt archive bundle

## Why this matters

The original files in the repo were distributed as ZIP archives; the real runtime is the extracted project directory. This directory preserves that working state in a normalized Git structure.
