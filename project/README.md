# NexFund Project

This directory is the unified Bolt/Vite React + TypeScript application scaffold created from the combined NexFund archive contents.

## Structure

- `src/` contains the application UI and runtime logic
- `supabase/` contains database and edge function configuration
- `docs/` contains the audit / automation notes recovered from the generated project bundle

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```
